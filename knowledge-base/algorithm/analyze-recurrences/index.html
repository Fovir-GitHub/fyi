Analyze Recurrences

The Iteration Method

Steps:

  1. Expand the recurrence a few times.
  2. Write the expanded form as a summation.
  3. Simplify the summation.
  4. Substitute the base condition to get the result.

Example 1

Given that:

T(n)=c+T(n/2) T(n) = c + T(n/2) T(n)=c+T(n/2)

Firstly, expand it.

T(n)=c+T(n/2)=c+c+T(n/4)=c+c+c+T(n/8)=…=kc+T(n/2k) \begin{align*} T(n) &= c + T(n/2) \\ &= c + c + T(n/4) \\ &= c + c + c + T(n/8) \\ &= \dots \\ &= kc + T(n/2^k) \end{align*} T(n)​=c+T(n/2)=c+c+T(n/4)=c+c+c+T(n/8)=…=kc+T(n/2k)​

Then, assume that:

n=2k⟹k=log⁡n n = 2^k \Longrightarrow k = \log{n} n=2k⟹k=logn

Finally, substitute it to the original expression:

T(n)=kc+T(n/2k)=clog⁡n+T(n/2log⁡n)=clog⁡n+T(1)=O(log⁡n) \begin{align*} T(n) &= kc + T(n/2^k) \\ &= c\log{n} + T(n/2^{\log{n}}) \\ &= c\log{n} + T(1) \\ &= O(\log{n}) \end{align*} T(n)​=kc+T(n/2k)=clogn+T(n/2logn)=clogn+T(1)=O(logn)​

Example 2

Given that:

T(n)={1n=1T(n−1)+log⁡nn>1 T(n) = \begin{cases} 1 &n=1 \\ T(n-1) + \log{n} &n>1 \end{cases} T(n)={1T(n−1)+logn​n=1n>1​

Then

T(n)=T(n−1)+log⁡n=T(n−2)+log⁡n+log⁡n−1=…=T(n−k)+∑i=1nlog⁡i=T(n−k)+log⁡(n!) \begin{align*} T(n) &= T(n-1) + \log{n} \\ &= T(n-2) + \log{n} + \log{n-1} \\ &= \dots \\ &= T(n-k) + \sum_{i=1}^{n}{\log{i}} \\ &= T(n-k) + \log{(n!)} \\ \end{align*} T(n)​=T(n−1)+logn=T(n−2)+logn+logn−1=…=T(n−k)+i=1∑n​logi=T(n−k)+log(n!)​

Since when n=1n=1n=1, T(n)=1T(n) = 1T(n)=1, so we assume that k=n−1k = n - 1k=n−1 finally.

Then

T(n)=T(1)+log⁡(n!)=1+log⁡(n!) T(n) = T(1) + \log{(n!)} = 1 + \log{(n!)} T(n)=T(1)+log(n!)=1+log(n!)

Use Stirling’s formula,

log⁡n=nlog⁡n−nlog⁡e+O(log⁡n)T(n)=1+log⁡(n!)T(n)=1+nlog⁡n−nlog⁡e+O(log⁡n)T(n)=O(nlog⁡n) \begin{align*} \log{n} &= n\log{n} - n\log{e} + O(\log{n}) \\ T(n) &= 1 + \log{(n!)} \\ T(n) &= 1 + n\log{n} - n\log{e} + O(\log{n}) \\ T(n) &= O(n\log{n}) \end{align*} lognT(n)T(n)T(n)​=nlogn−nloge+O(logn)=1+log(n!)=1+nlogn−nloge+O(logn)=O(nlogn)​

The Substitution/Induction Method

Steps:

  1. Guess the result form.
  2. Prove by induction.

Example

Given that

T(n)=2T(n2)+n T(n) = 2T(\frac{n}{2}) + n T(n)=2T(2n​)+n

Firstly, we guess that T(n)∈O(nlog⁡n)T(n) \in O(n\log{n})T(n)∈O(nlogn)

So we need to prove that T(n)≤c⋅nlog⁡nT(n) \le c \cdot n\log{n}T(n)≤c⋅nlogn

Assume that

T(n2)≤c⋅n2log⁡n2 T(\frac{n}{2}) \le c \cdot \frac{n}{2}\log{\frac{n}{2}} T(2n​)≤c⋅2n​log2n​

Then the inductive steps are:

T(n)=2T(n2)+n≤2(c⋅n2log⁡n2)+n=cnlog⁡n2+n=cn(log⁡n−1)+n=cnlog⁡n−(c−1)n≤cnlog⁡n∀c≥1∴T(n)∈O(nlog⁡n) \begin{align*} T(n) &= 2T(\frac{n}{2}) + n \\ &\le 2(c \cdot \frac{n}{2}\log{\frac{n}{2}}) + n \\ &= cn\log{\frac{n}{2}} + n \\ &= cn(\log{n} - 1) + n \\ &= cn\log{n} - (c - 1)n \\ &\le cn\log{n} \quad \forall c \ge 1 \\ \therefore T(n) &\in O(n\log{n}) \end{align*} T(n)∴T(n)​=2T(2n​)+n≤2(c⋅2n​log2n​)+n=cnlog2n​+n=cn(logn−1)+n=cnlogn−(c−1)n≤cnlogn∀c≥1∈O(nlogn)​

Master Method

Suppose that we have:

T(n)=aT(nb)+f(n)a≥1,b>1 T(n) = aT(\frac{n}{b}) + f(n) \quad a \ge 1, b \gt 1 T(n)=aT(bn​)+f(n)a≥1,b>1
  • nnn is the size of the current problem.
  • aaa is the number of sub problems of the recursion.
  • nb\frac{n}{b}bn​ is the size of each sub problem.
  • f(n)f(n)f(n) is the cost of each level recursion.

Then we have three theorems:

  1. If f(n)=O(nlog⁡ba−ϵ)f(n) = O(n^{\log_b{a} - \epsilon})f(n)=O(nlogb​a−ϵ), then T(n)=Θ(nlog⁡ba)T(n) = \Theta(n^{\log_b{a}})T(n)=Θ(nlogb​a)
  2. If f(n)=Θ(nlog⁡ba)f(n) = \Theta(n^{\log_b{a}})f(n)=Θ(nlogb​a), then T(n)=Θ(nlog⁡balog⁡n)T(n) = \Theta(n^{\log_b{a}}\log{n})T(n)=Θ(nlogb​alogn)
  3. If f(n)=Ω(nlog⁡ba+ϵ)f(n) = \Omega(n^{\log_b{a} + \epsilon})f(n)=Ω(nlogb​a+ϵ), and if af(nb)≤cf(n)af(\frac{n}{b}) \le cf(n)af(bn​)≤cf(n) for some c<1c \lt 1c<1, and all sufficiently large nnn, then T(n)=Θ(f(n))T(n)=\Theta(f(n))T(n)=Θ(f(n)).

Example 1

Given that

T(n)=2T(n2)+n T(n) = 2T(\frac{n}{2}) + n T(n)=2T(2n​)+n

Then

a=2,b=2,f(n)=nnlog⁡ba=nnlog⁡ba=f(n)∴T(n)=Θ(nlog⁡balog⁡n)=Θ(nlog⁡(n)) \begin{align*} a = 2, b &= 2, f(n) = n \\ n^{\log_b{a}} &= n \\ n^{\log_b{a}} &= f(n) \\ \therefore T(n) &= \Theta(n^{\log_b{a}}\log{n}) \\ &= \Theta(n\log(n)) \end{align*} a=2,bnlogb​anlogb​a∴T(n)​=2,f(n)=n=n=f(n)=Θ(nlogb​alogn)=Θ(nlog(n))​

Example 2

Given that

T(n)=9T(n3)+n T(n) = 9T(\frac{n}{3}) + n T(n)=9T(3n​)+n

Then

a=9,b=3,f(n)=nnlog⁡ba=n2nlog⁡ba≥f(n)=n∴f(n)=O(nlog⁡ba−ϵ)=O(n2−ϵ)∴T(n)=Θ(n2) \begin{align*} a = 9, b &=3, f(n) = n \\ n^{\log_b{a}} &= n^2 \\ n^{\log_b{a}} &\ge f(n) = n \\ \therefore f(n) &= O(n^{\log_b{a} - \epsilon}) \\ &= O(n^{2 - \epsilon}) \\ \therefore T(n) &= \Theta(n^2) \end{align*} a=9,bnlogb​anlogb​a∴f(n)∴T(n)​=3,f(n)=n=n2≥f(n)=n=O(nlogb​a−ϵ)=O(n2−ϵ)=Θ(n2)​

Example 3

Given that

T(n)=3T(n4)+nlog⁡n T(n) = 3T(\frac{n}{4}) + n\log{n} T(n)=3T(4n​)+nlogn

Then

a=3,b=4,f(n)=nlog⁡nnlogba=nlog43<n<f(n) \begin{align*} a = 3, b &= 4, f(n) = n\log{n} \\ n^{log_b{a}} &= n^{log_4{3}} \lt n \lt f(n) \\ \end{align*} a=3,bnlogb​a​=4,f(n)=nlogn=nlog4​3<n<f(n)​

Before applying case 3, we need to check the regularity condition, which means that af(nb)≤cf(n)af(\frac{n}{b}) \le cf(n)af(bn​)≤cf(n) where c<1c \lt 1c<1 should be true.

af(nb)=3f(n4)=34nlog⁡n4cf(n)=cnlog⁡n∴34nlog⁡n4≤cnlog⁡n \begin{align*} af(\frac{n}{b}) &= 3f(\frac{n}{4}) \\ &= \frac{3}{4}n\log{\frac{n}{4}} \\ cf(n) &= cn\log{n} \\ \therefore \frac{3}{4}n\log{\frac{n}{4}} &\le cn\log{n} \\ \end{align*} af(bn​)cf(n)∴43​nlog4n​​=3f(4n​)=43​nlog4n​=cnlogn≤cnlogn​

When c=34c = \frac{3}{4}c=43​, the expression is true. So the condition check is successfully.

f(n)=Ω(nlog⁡ba+ϵ)=Ω(nlog⁡43+ϵ)∴T(n)=Θ(f(n))=Θ(nlog⁡n) \begin{align*} f(n) &= \Omega(n^{\log_b{a} + \epsilon}) = \Omega(n^{\log_{4}{3} + \epsilon}) \\ \therefore T(n) &= \Theta(f(n)) \\ &= \Theta(n\log{n}) \end{align*} f(n)∴T(n)​=Ω(nlogb​a+ϵ)=Ω(nlog4​3+ϵ)=Θ(f(n))=Θ(nlogn)​
